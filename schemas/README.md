# Esquemas

Este directorio alojará contratos serializables una vez definidos y validados.

Todo esquema deberá:

- excluir secretos y datos reales de los ejemplos;
- versionarse explícitamente;
- distinguir campos normativos de metadatos;
- documentar invariantes y compatibilidad;
- incluir casos válidos, inválidos y de pérdida semántica;
- permitir pruebas de serialización y reconstrucción.
