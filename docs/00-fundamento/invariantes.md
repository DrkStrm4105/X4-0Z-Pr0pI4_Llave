# Invariantes fundacionales

Toda implementación deberá conservar:

1. **Soberanía:** el sujeto conserva la capacidad de autorizar, negar y revocar.
2. **Separación:** identidad, credencial, llave, prueba y permiso no son equivalentes.
3. **Minimización:** cada operación expone únicamente lo imprescindible.
4. **Temporalidad:** estados y autorizaciones tienen orden causal y vigencia.
5. **Trazabilidad:** toda transición relevante puede reconstruirse.
6. **Revocabilidad:** detener efectos futuros no exige reescribir el pasado.
7. **Recuperabilidad:** la pérdida de un componente no implica necesariamente pérdida total.
8. **No amplificación:** ningún adaptador o interfaz puede aumentar privilegios.
9. **Interoperabilidad:** las traducciones preservan significado o declaran explícitamente su pérdida.
10. **Falsabilidad:** una hipótesis criptográfica permanece experimental hasta superar revisión y ataque independientes.
