# Propósito

## Tesis

Diseñar una arquitectura donde identidad, prueba, llave y permiso permanezcan distinguibles, trazables y revocables.

## Objetivos

- Preservar continuidad de identidad sin centralización rígida.
- Minimizar exposición de secretos y datos personales.
- Separar autorización presente de capacidad soberana futura.
- Permitir reconstrucción auditable de estados y transiciones.
- Someter toda propuesta criptográfica a pruebas destructivas antes de considerarla segura.

## No objetivos iniciales

- Crear una criptomoneda.
- Almacenar identidades o claves reales.
- Sustituir estándares criptográficos probados.
- Declarar seguridad, universalidad o resistencia cuántica sin evidencia.
- Construir una aplicación completa antes de validar una cápsula mínima.
